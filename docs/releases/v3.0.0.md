# Pikachu Volleyball 3.0.0

Pikachu Volleyball 3.0.0 is a major Linux desktop release that keeps the classic game intact while replacing the desktop runtime with a compact native architecture.

## Highlights

- Move the supported Linux desktop edition from Electron to SDL3 + QuickJS.
- Keep the original physics, AI, scoring, timing and gameplay behavior protected by the shared regression core.
- Deliver a much smaller AppImage while preserving direct launch, reproducible builds and the existing browser/PWA build.
- Refresh the native menu with clearer proportional typography, the established colorful visual language and corrected Restart/Quit confirmation dialogs.
- Preserve editable controls, quick rematch, practice mode, Sharp/Soft graphics, light/dark themes, BGM and stereo/mono/off SFX.
- Keep all five production languages: English, Español, Català, 한국어 and 中文.
- Provide native accessibility semantics through AccessKit/AT-SPI.
- Automatically migrate supported Pikachu Volleyball 2.1 desktop preferences on first native launch when an eligible legacy profile is available.

## Linux release

The Linux desktop build is distributed as a single x86_64 AppImage.

The final release workflow produces:

```text
Pikachu-Volleyball-3.0.0-x86_64.AppImage
SHA256SUMS.txt
```

Verify the downloaded AppImage from the same directory:

```bash
sha256sum -c SHA256SUMS.txt
chmod +x Pikachu-Volleyball-3.0.0-x86_64.AppImage
./Pikachu-Volleyball-3.0.0-x86_64.AppImage
```

## Compatibility and preservation

Version 3.0 changes the Linux desktop runtime and packaging architecture, not the game rules. The browser/PWA build remains part of the project, and the accepted gameplay, control, localization and settings behavior remains covered by the v3 regression and release-readiness gates.
