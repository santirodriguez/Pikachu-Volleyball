# Pikachu Volleyball 2.1.0

Pikachu Volleyball 2.1.0 is a maintenance and reliability release focused on making the Linux edition faster to open, safer to package and easier to maintain without changing the classic gameplay.

## Highlights

- Restore fast Linux startup. An over-compressed AppImage candidate could take roughly one minute to open on real Fedora hardware; the final package returns launch time to roughly two seconds on the Fedora system used for validation.
- Make the size/speed trade-off explicit: 2.1 accepts the modest package-size increase required for fast startup, then removes redundant packaged content and optimizes the package as far as practical without reintroducing the startup regression or reducing compatibility.
- Harden Linux desktop packaging and Chromium sandbox behavior so sandbox-relaxing launch paths are rejected instead of silently falling back to a less secure configuration.
- Simplify the game runtime, settings and integrated-menu internals, including the Restart input-recovery fix, while preserving browser/PWA support and all five supported languages.
- Preserve the classic game: physics, AI, collisions, scoring and historical 25 Hz game timing remain unchanged.

## Linux release focus

The goal of 2.1 is not the smallest AppImage at any cost. A smaller, aggressively compressed candidate showed that package size alone was the wrong target when it made a tiny game take roughly a minute to open. The final build deliberately prioritizes fast real-world startup, then recovers safe size savings around that constraint.

Real Fedora behavior is the release authority for startup. The final AppImage was manually validated with roughly two-second startup on the test system and normal gameplay, menu and desktop behavior.

## Download and verification

The GitHub release will provide:

```text
Pikachu-Volleyball-2.1.0-x86_64.AppImage
SHA256SUMS.txt
```

Verify the downloaded AppImage from the same directory:

```bash
sha256sum -c SHA256SUMS.txt
chmod +x Pikachu-Volleyball-2.1.0-x86_64.AppImage
./Pikachu-Volleyball-2.1.0-x86_64.AppImage
```
