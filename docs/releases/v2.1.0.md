# Pikachu Volleyball 2.1.0

A maintenance and performance release that makes the Linux edition leaner and simplifies the application UI/runtime boundaries without changing the game simulation.

## Highlights

- Reduce the Linux AppImage by about 10% compared with the 2.0.0 reference build by removing packaged dependency copies that Webpack already bundles.
- Keep the stable Electron 35.7.5 and electron-builder 26.8.1 toolchain while packaging only the required `en-US` Electron locale.
- Paint the lightweight application shell before dynamically loading the heavier PixiJS/game runtime.
- Centralize persisted game settings and make `GameCommands` plus the integrated menu the active game-page UI authority.
- Remove the obsolete DOM toolbar, legacy About overlay, winning-score notices and unused `ui.js` implementation.
- Fix Restart leaving the menu in modal input mode, which could swallow gameplay keys and eventually allow the inactivity AI-vs-AI flow to start.
- Preserve English, Spanish, Catalan, Korean and Chinese production outputs, browser/PWA support and the existing desktop security boundary.

## Gameplay preservation

Pikachu Volleyball 2.1.0 does not intentionally change physics, AI, scoring, collision behavior, game timing or the validated default control contract.

Player control remapping, match settings, audio, graphics, interface theme, language switching, quick rematch and desktop Quit continue through the integrated menu.

## Download and verification

The GitHub release will provide:

```text
Pikachu-Volleyball-2.1.0-x86_64.AppImage
SHA256SUMS.txt
```

Verify the downloaded AppImage from the same directory:

```bash
sha256sum -c SHA256SUMS.txt
chmod +x Pikachu-Volleyball-2.1.0-x86_64.AppImage
./Pikachu-Volleyball-2.1.0-x86_64.AppImage
```
