# Pikachu Volleyball for Linux 3.0.1

A focused Linux experience and presentation update built on the native SDL3 +
QuickJS architecture introduced in 3.0.0.

## Highlights

- Establish **Pikachu Volleyball for Linux** as the display name across native
  windows, menus, accessibility and Web/PWA metadata.
- Refine native and browser menus with clearer light/dark contrast, readable
  hierarchy, a useful Continue panel, grouped player controls and visible selection.
- Improve keyboard focus, Tab/Shift+Tab navigation, pointer feedback, modal bounds
  and accessibility semantics. Add a pointer/accessibility-openable native menu trigger.
- Harden destructive confirmations: start Restart/Quit on Cancel and require a
  fresh confirmation press, without changing gameplay input semantics.
- Persist the selected native language across launches with compatible preferences.
- Clean up current Spanish, Catalan and Simplified Chinese copy, localize menu help
  and retain English, Español, Català, 한국어 and 中文.
- Remove a stale stylesheet request and provide localized browser menu-load
  failure/retry feedback.
- Refresh public native screenshots, contributor ownership guides and reusable
  manual/release checklists; prepare matching version metadata and update histories.

## Preservation and compatibility

Physics, AI, collisions, scoring, RNG order and game timing remain unchanged.
Default controls, quick rematch, practice/reset, audio options, Sharp/Soft graphics
and the shared gameplay core are preserved. Linux remains an x86_64 SDL3 + QuickJS
AppImage; Web/PWA remains supported. Existing executable, desktop/icon and storage
identities stay stable, including supported legacy 2.1 preference migration.
No new runtime dependency or packaging format is introduced.

## Validation and download

PR #99 records the exact release-candidate source SHA, workflow/artifact identities,
measured checksum, size and startup observations, plus manual evidence and remaining
bounded checks. Automated readiness covers core parity, reproducibility,
dependency/license/security closure, migration, AT-SPI and representative Linux
runtime checks; it is not a claim of universal desktop compatibility.

For the published release, the existing release workflow produces
`Pikachu-Volleyball-3.0.1-x86_64.AppImage` and `SHA256SUMS.txt` from the
definitive release tag. Verify with `sha256sum -c SHA256SUMS.txt` before launch.
