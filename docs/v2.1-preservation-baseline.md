# Pikachu Volleyball 2.1 Preservation Baseline

This document is the frozen behavioral and operational regression baseline for Pikachu Volleyball 2.1 while Version 3 is developed. It records accepted behavior that may be reorganized internally but must remain available unless a later task explicitly changes the requirement with sufficient regression evidence.

The frozen source commit is:

`d7735b13654904a5b48a0c2d1217c8b8507a8409`

The historical `docs/2.0-preservation-matrix.md` remains a record of the 2.0 development cycle and is not an active authority for v3 work.

## Characterization targets

The v3 regression suite should freeze externally meaningful behavior without rewriting the 2.1 state machine. Material targets include:

1. initial ball/world behavior, collision outcomes and power-hit semantics;
2. deterministic AI decisions for representative reachable-ball scenarios;
3. intro skip and automatic intro completion;
4. original mode selection and the 225-frame AI-versus-AI inactivity boundary;
5. pause and resume without advancing game state;
6. restart returning to the intro with input immediately usable;
7. practice-mode B reset and its practice/round guard;
8. scoring on each side, six-step slow motion and next-round transition;
9. winning-score boundary and game-end transition;
10. quick-rematch availability at frame 70;
11. automatic return to intro at game-end frame 211;
12. critical frame totals: intro 165, post-selection 15, pre-game 15, game-start 71, post-round 5 and next-round 30.

Tests should assert externally meaningful state and collaborator behavior rather than private implementation trivia. Deterministic RNG may be used where needed.

## Review rule

Every v3 implementation pull request must identify the preservation areas it affects and how those areas were validated. No task receives implicit authority to change physics, AI, scoring rules, collision equations or timing values.
